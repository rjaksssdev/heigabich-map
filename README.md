# 해가빛 캠핑장 실시간 자리 현황

충남 서천 **해가빛 캠핑장**(37개 사이트)의 네이버 예약 현황을 배치도 위에 겹쳐 보여 주는 웹페이지입니다.

- 배포 주소: <https://rjaksssdev.github.io/heigabich-map/>
- 네이버 예약: <https://booking.naver.com/booking/3/bizes/667875>
- 카페: <https://cafe.naver.com/heigabichcamping>

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 페이지 전체 (CSS·JS 포함, 외부 라이브러리 없음) |
| `assets/map.png` | 캠핑장 배치도 원본 이미지 (1262 × 567, 하단 내장 범례 크롭본) |
| `data/sites.json` | 37개 사이트의 배치도 위 좌표(%)·존 정보, 네이버 상품 id(`naverItemId`) |
| `data/status.json` | 날짜별 사이트 예약 상태 (총무 비서 JSON → `work/sync_status.py` 로 변환) |

## 현황 갱신 방법

`data/status.json`만 바꾸면 배치도 색과 숫자가 자동으로 반영됩니다.

배치도 표시 규칙:

- **예약가능** — 원본 칸 색 그대로 + 에메랄드 테두리 (유일하게 강조)
- **확정 · 이용완료** — 배지 없이 칸만 어두운 회색으로 톤다운
- **예약불가(미판매) · 예약불가(판매차단)** — 배지 없이 칸만 밝은 회색으로 톤다운
- 범례·요약 카운트·칸을 눌렀을 때 하단 정보바에는 원문 상태 이름이 표시됩니다.
  (예: `예약완료`, `이용완료`, `예약불가 · 판매차단`)

## 사이트별 예약 딥링크

배치도에서 예약 가능한 사이트를 누르면 정보바에 `예약하기 ↗` 가 나옵니다.
이 링크는 캠핑장 전체 페이지가 아니라 **그 사이트가 선택된 네이버 예약 상품 페이지**로 열립니다.

```
https://booking.naver.com/booking/3/bizes/667875/items/{naverItemId}?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD+1
```

- `naverItemId` 는 `data/sites.json` 에 사이트별로 들어 있습니다(노출 29개 사이트).
- `startDate`·`endDate` 는 지금 보고 있는 날짜와 그다음 날(1박)입니다. 두 값이 모두 있어야 네이버가 날짜를 채운 채로 열립니다.
- 사이트 id 가 없는 미판매 8개 사이트는 예약 가능으로 표시되지 않으므로 링크가 필요 없고, 혹시 상태가 바뀌면 캠핑장 전체 예약 페이지로 대체됩니다.
- 날짜는 채워 두되 예약은 하지 않습니다. 인원 선택·결제는 손님이 네이버 예약 화면에서 진행합니다.

날짜 바는 **오늘 이후 날짜 중 실제로 운영하는 날**(예약가능·예약완료 자리가 하나라도 있는 날)만
추려서 **7일씩** 보여 주고, 좌우 화살표로 앞/뒤 날짜 묶음을 넘깁니다.

- 지난 날짜는 표시하지 않습니다.
- 전체 사이트가 `휴무`(또는 전부 예약불가)인 날은 목록에서 빠집니다.
- 묶음이 하나뿐이면 화살표는 비활성으로 보입니다.
- 현황이 모두 지난 날짜뿐이면 최근 운영일을 보여 주고 날짜 바 아래에 안내 문구가 나옵니다.

```json
{
  "updatedAt": "2026-11-22T16:40:00+09:00",
  "dates": [
    {
      "date": "2026-11-28",
      "label": "11/28",
      "weekday": "토",
      "status": { "sol8": "확정", "bit3": "확정", "hae1": "예약가능", "sol3": "예약불가(미판매)" }
    }
  ]
}
```

- 상태값(원문 그대로): `예약가능` · `확정` · `이용완료` · `예약불가(미판매)` · `예약불가(판매차단)` · `휴무`
- 사이트 id: `sol1`~`sol12`, `deck1`~`deck7`(`deck1-1` 처럼 `-1` 포함), `gravel8`, `gravel8-1`, `bit1`~`bit4`, `hae1`~`hae5`
- `label`은 탭에 표시되는 글자(예: `11/28`), `weekday`는 `금`·`토`·`일`
- 상태가 빠진 사이트는 배치도에서 `예약가능`으로 보입니다.
